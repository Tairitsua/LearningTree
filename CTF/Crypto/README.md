## 阅读建议

1. 入门先读 [密码种类与特征](密码种类与特征.md) 与 [密码攻击方式](密码攻击方式.md) 建立分类与攻击模型概念。
2. 刷题时以 [古典密码速查](古典密码速查.md)、[趣味编码速查](趣味编码速查.md)、[编码速查](编码速查.md) 三张速查表对照特征。
3. `RSA` 类题目从 [RSA与数论](RSA与数论.md) 的「工具与攻击」入手。
